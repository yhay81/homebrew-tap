# Homebrew tap

Official Homebrew formulae for projects maintained by
[@yhay81](https://github.com/yhay81).

## sqrail

Install [sqrail](https://sqrails.yhay81.com):

```sh
brew install yhay81/tap/sqrail
```

The formula builds the tagged sqrail source and links it to Homebrew's packaged
DuckDB. Formula tests verify the reported sqrail and DuckDB versions and execute
queries over generated and CSV inputs.
