# Homebrew tap

Official Homebrew formulae for projects maintained by
[@yhay81](https://github.com/yhay81).

## sqrail

Install [sqrail](https://yhay81.github.io/sqrail/):

```sh
brew install yhay81/tap/sqrail
```

The formula selects the native, prebuilt release for macOS or Linux on Arm64
or x86-64 and verifies its SHA-256 checksum before installation.
